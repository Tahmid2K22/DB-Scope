# bob_sessions/

This folder contains IBM Bob IDE task session summary screenshots as **mandatory evidence** of Bob usage for the IBM Bob 2.0 Hackathon.

## Screenshot Naming Convention

```
astrochari_task<NN>summary.png
```

**Examples:**
- `astrochari_task01summary.png`
- `astrochari_task02summary.png`
- `astrochari_task03summary.png`
- `astrochari_task04summary.png`
- `astrochari_task05summary.png`

## What Each Screenshot Should Show

| # | Screenshot | Bob Feature Demonstrated |
|---|-----------|--------------------------|
| 1 | Bob in `schema-analyst` custom mode parsing SQL migration files | Custom Modes |
| 2 | Bob spawning 4 parallel subagents for blast radius analysis | Parallel Subagents |
| 3 | Bob using MCP tool to search GitHub codebase for table references | MCP Tool Calls |
| 4 | Bob reading README.md and detecting documentation drift | Document Understanding |
| 5 | Task Session Consumption Summary showing Bobcoins used | Bobcoin Usage |

> **Note:** All screenshots must be from the hackathon-provisioned account (`ibm-coding-challenge-uat`), **not** a personal Bob account.
